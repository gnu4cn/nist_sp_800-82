# 维护 (PR.MA)

属于 CSF 维护类别的成果，为对信息系统组件进行例行和预防性维护提供了指导。这包括使用本地和远程维护工具，以及维护人员的管理。

**特定于运营技术（OT）的建议与指南**

维护跟踪的解决方案，使组织能够对运营技术（OT）的维护和维修活动进行计划、跟踪、授权、监控和审计，并确保维护日志或变更得到妥善记录。记录这些事件可形成审计轨迹，有助于开展与网络安全相关的故障排除、响应和恢复工作。维护跟踪还能提供运营技术设备计划维护情况的可见性，并为设备报废决策提供依据。

用于 OT 维护活动的软件，应经组织批准并受到管控。经批准的软件应直接从供应商处获取，并验证其真实性。例如，通过验证证书或比较安装程序的哈希值。

对 OT 设备进行的任何维护，都可能无意中修改其配置，从而增加攻击面，attack surface。无论进行何种维护，都应保持 OT 设备的加固状态。在维护和软件补丁更新后，应验证设备配置，因为某些功能可能已被无意中重新启用，或安装了新功能。应从设备供应商处获取最佳实践和其他支持文档，以指导和告知维护活动。

限制在维护活动中某些设备的使用，有助于降低因接触外部网络、未经授权的用户，或因设备失窃而导致设备安全受损的风险。在 OT 环境中保持安全的维护设备，能够降低其暴露风险。应限制或尽量减少在 OT 环境外使用维护设备，或将设备连接到非 OT 网络的情况。

任何连接到 OT 系统的设备，在维护活动完成后均应断开连接，并移除任何临时连接。

应充分了解用于维护活动设备的操作方式、功能和特性。设备可能包含无线电模组及其他通信设备，这些组件可能易受侧信道攻击，side-channel attacks，或允许网络间同时连接（即双网口配置）。应仔细查阅供应商文档以了解这些功能。
