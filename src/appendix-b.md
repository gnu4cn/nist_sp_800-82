# 附录 B，术语表

本文所用部分术语的定义如下。部分定义附有来源出处。

## a

- access control list, 访问控制列表

    一种通过列举获准访问系统资源的系统实体的身份，从而对系统资源实施访问控制的机制。【[RFC4949](./refs.md#rfc4949)】（改编）

- actuator, 执行器

    用于移动或控制机械装置或系统的设备。他由能量源（通常是电流、液压或气压）驱动，并将该能量转化为运动。执行器是控制系统作用于环境的机制。控制系统可以是简单的（固定的机械或电子系统）、基于软件的（例如打印机驱动程序、机器人控制系统），或是人或其他代理。

- alarm，报警

    一种通过产生可听见或可见的离散变化（或两者兼有），来指示异常状况存在的设备或功能，从而引起对该状况的注意。【[ANSI-ISA-5-1](./refs.md#ansi-isa-5-1)】

- antivirus tools, 防病毒工具

    用于检测恶意代码、防止其感染系统以及清除已感染系统的恶意代码的软件产品和技术。

- attack, 攻击

    试图未经授权访问系统服务、资源或信息，或试图破坏系统完整性、可用性或保密性的行为。

- authentication, 身份验证

    验证用户、进程或设备的身份，通常是允许访问信息系统资源的先决条件。【[FIPS200](./refs.md#fips200)】

- authorization, 授权

    授予系统实体访问系统资源的权利或许可。【[RFC4949](./refs.md#rfc4949)】（改编）


## b


- backdoor, 后门

    一种未记录的访问计算机系统的方法。后门属于一种潜在的安全风险。

- buffer overflow, 缓冲区溢出

    指在接口处，输入数据量超过缓冲区或数据存储区域的分配容量，从而覆盖其他信息的情况。攻击者利用这种情况使系统崩溃，或植入经过特殊设计的代码以控制系统。【[SP800-28v2](./refs.md#sp800-28v2)】


## c

- cleartext, 明文

    未经过加密的信息。

- communications router, 通信路由器

    一种在两个网络之间传输消息的通信设备。路由器的常见用途包括将局域网 LAN 连接到广域网 WAN，以及将 MTU 和 RTU 连接到长距离网络介质，以实现 SCADA 通信。

- confidentiality, 保密性

    维护对信息访问和披露的授权限制，包括保护个人隐私和专有信息的手段。【[USC44-3552](./refs.md#usc44-3552)】（改编）

- configuration (of a system or device)，配置（系统或设备的）

    系统设计中的步骤；例如，选择功能单元、分配其位置以及定义其互连关系。

- configuration control, 配置控制

    用于控制硬件、固件、软件及文档修改的过程，以确保信息系统在系统实施前、实施期间及实施后免受不当修改的影响。【[CNSS4009](./refs.md#cnss4009)】（改编）

- control, 控制

    用于监测和控制物理过程的 OT 系统部分。这包括所有控制服务器、现场设备、执行器、传感器及其配套通信系统。

- control algorithm, 控制算法

    待执行控制动作的数学表示。【[ISADICT](./refs.md#isadict)】

- control center, 控制中心

    用于测量、控制和/或监测过程的设备结构或一组结构。【[ANSI-ISA-51-1](./refs.md#ansi-isa-51-1)】

- control loop, 控制回路

    控制回路由用于测量的传感器、控制器硬件（如 PLC）、执行器（如控制阀、断路器、开关和电机），以及变量通信组成。被控变量由传感器传输至控制器。控制器对信号进行解译，并根据设定值生成相应的操纵变量，将其传输至执行器。受扰动影响的工艺变化，会产生新的传感器信号，这些信号反映工艺状态，并再次传输至控制器。

- control network, 控制网络

    企业的这些网络通常连接到控制物理过程的设备，且这些过程具有时间敏感性或安全关键性。控制网络可以划分为多个区域，并且在一个企业或站点内可能存在多个独立的控制网络。

<a name="control_server"></a>
- control server, 控制服务器

    一种既充当控制器又充当服务器的设备，他运行控制软件，并通过运营技术（OT）网络，与远程终端单元（RTU）和可编程逻辑控制器（PLC）等低级控制设备进行通信。在 SCADA 系统中，这通常被称为 SCADA 服务器、MTU 或监督控制器。

- control system，控制系统

    一种通过有意识的引导或操作，来使变量达到规定值的系统。控制系统包括 SCADA、DCS、PLC、BAS 以及其他类型的 OT 测量和控制系统。

- controlled variable，被控变量

    控制系统试图将其保持在设定点值的变量。设定点可以是恒定的，也可以是可变的。【[ISADICT](./refs.md#isadict)】

- controller, 控制器

    一种自动运行以调节受控变量的设备或程序。【[ANSI-ISA-51-1](./refs.md#ansi-isa-51-1)】

- cycle time, 循环时间

    控制器完成一个控制循环所需的时间（通常以秒为单位），该循环包括将传感器信号读入内存、执行控制算法，以及将相应的控制信号传输至执行器，从而对制程产生变化，并产生新的传感器信号。【[ISADICT](./refs.md#isadict)】


## d


- data diode, 数据二极管

    一种仅允许数据单向传输的网络设备或装置。也称为单向网关、确定性单向边界设备或单向网络。

- data historian, 数据历史库

    支持使用统计过程控制技术，statistical process control techniques, 进行数据分析的集中式数据库。

- database, 数据库

    一个通常存储全厂信息的资料库，其中包括工艺数据、配方、人员数据和财务数据。【[IR6859](./refs.md#ir6859)】（改编）

- demilitarized zone, 非军事区 DMZ

    路由防火墙上的一种接口，其特性与防火墙受保护侧的接口相似。在 DMZ 与防火墙受保护侧的其他接口之间传输的流量仍需经过防火墙，并可应用防火墙保护策略。【[SP800-41r1](./refs.md#sp800-41r1)】

- denial of service, 拒绝服务

    阻止对系统资源的授权访问，或延迟系统操作和功能。【[RFC4949](./refs.md#rfc4949)】

- diagnostics, 诊断

    有关已知故障模式及其特征的信息。此类信息可用于故障排除和故障分析，以帮助确定故障原因并制定适当的纠正措施。【[ISADICT](./refs.md#isadict)】

- disaster recovery plan, 灾难恢复计划

    针对重大硬件或软件故障或设施损毁情况，处理关键应用程序的书面计划。【[SP800-34r1](./refs.md#sp800-34r1)】（改编）

- discret process, 离散过程

    一种工艺类型，其中指定数量的物料作为单元（零件或零件组）在工作站之间移动，且每个单元保持其唯一标识。【[ISADICT](./refs.md#isadict)】

- distributed control system, 分布式控制系统

    在控制系统中，指通过分布在被控过程各处的智能单元实现控制，而非由位于中央的单一单元实现控制。 【[ISADICT](./refs.md#isadict)】

- disturbance, 扰动

    作用于系统中的变量所发生的、倾向于对受控变量值产生不利影响的意外变化。 【[ANSI-ISA-51-1](./refs.md#ansi-isa-51-1)】

- domain, 域

    一种环境或上下文，其中包含一组系统资源以及一组具有访问这些资源权限的系统实体，这些权限由共同的安全策略、安全模型或安全架构所定义。【[RFC4949](./refs.md#rfc4949)】（改编）



## e


- encryption, 加密

    将数据（称为 “明文”）转换为一种形式（称为 “密文”），以隐藏数据的原始含义，从而防止其被知晓或使用。当该转换是可逆的时，则相应的逆向过程称为 “解密”，即一种将加密数据恢复到原始状态的转换。【[RFC4949](./refs.md#rfc4949)】（改编）

- enterprise, 企业

    协调一个或多个处理站点运行的组织。


## f


- fault tolerant, 容错

    指系统具备内置能力，可在出现硬件和/或软件故障时，仍能持续、正确地执行其分配的功能。

- field device, 现场设备

    连接到 ICS 现场侧的设备。现场设备的类型包括远程终端单元（RTU）、可编程逻辑控制器（PLC）、执行器、传感器、人机界面（HMI）及相关通信设备。

- field site, 现场站点

    指在 ICS 内通过物理、地理或逻辑划分所标识的子系统。一个现场站点可能包含远程终端单元（RTU）、可编程逻辑控制器（PLC）、执行器、传感器、人机界面（HMI）及相关通信设备。

- fieldbus, 现场总线

    一种数字、串行、多点接入、双向的数据总线，或用于连接底层工业现场设备（如传感器、变送器、执行器、本地控制器，甚至控制室设备）之间的通信路径或链路。采用现场总线技术可免除控制器与各设备之间点对点的布线。现场总线网络通过协议来定义消息，每条消息都标识网络上的特定传感器。

- File Transfer Protocol, 文件传输协议 FTP

    一种用于通过互联网传输文件的标准。FTP 程序和实用工具用于在本地介质与允许 FTP 访问的远程服务器之间上传和下载网页、图形及其他文件。

- firewall，防火墙

    一种网络间网关，用于限制连接网络之一（即所谓的 “防火墙内部” 网络）与外部网络之间的数据通信流量，从而保护该网络的系统资源免受来自另一网络（即所谓的 “防火墙外部” 网络）的威胁。【[RFC4949](./refs.md#rfc4949)】



## h


- human-machine interface，人机界面

    操作员与控制器交互所使用的硬件或软件。HMI 的形式多种多样，从带有按钮和指示灯的物理控制面板，到运行专用 HMI 软件，并配备彩色图形显示屏的工业电脑。【[IR6859](./refs.md#ir6859)】


## i


- identification, 身份验证

    验证用户、程序进程或设备身份的过程，通常是授予 IT 系统资源访问权限的先决条件。【[SP800-47](./refs.md#sp800-47)】

- incident, 事件

    指实际或潜在危及信息系统，或该系统处理、存储或传输的信息的机密性、完整性或可用性的事件，或构成对安全政策、安全程序或可接受使用政策的违反，或即将违反的威胁的事件。【[FIPS200](./refs.md#fips200)】

- industrial control system, 工业控制系统

    一个总称，涵盖多种类型的控制系统，包括监督控制与数据采集 SCADA 系统、分布式控制系统 DCS，以及其他常见于工业领域和关键基础设施的控制系统配置，例如可编程逻辑控制器 PLC。工业控制系统 ICS 由多种控制组件（例如电气、机械、液压、气动组件）组合而成，这些组件协同工作，以实现工业目标（例如制造、物质或能量的运输）。

- information security program plan, 信息安全计划

    正式文件，概述了全组织信息安全计划的安全要求，并描述了为满足这些要求而已实施，或计划实施的计划管理控制措施和通用控制措施。【[OMB-A130](./refs.md#omb-a130)】

- input/output，输入/输出

    用于与计算机通信的设备，以及通信中所涉及数据的统称。【[ISADICT](./refs.md#isadict)】

- insider, 内部人员

    位于安全边界内、虽获授权访问系统资源，但其使用方式未获授权方批准的实体。

- integrity，完整性

    防范信息被不当修改或破坏，包括确保信息的不可否认性和真实性。【[USC44-3552](./refs.md#usc44-3552)】（改编）

- intelligence electronic device，智能电子设备

    任何集成一个或多个处理器，且具备与外部源接收或发送数据/控制的能力的设备（例如，电子多功能电表、数字继电器、控制器）。【[AGA12](./refs.md#aga12)】

- internet, 互联网

    由商业、政府、教育及其他计算机网络组成、相互连接的全球性系统，这些网络共享由互联网架构委员会，Internet Architecture Board, IAB 规定的协议集，以及由互联网名称与数字地址分配机构 ICANN 管理的名称和地址空间。【[RFC4949](./refs.md#rfc4949)】（改编）

- intrusion detection system, 入侵检测系统

    一种安全服务，用于监控和分析网络或系统事件，旨在发现未经授权访问系统资源的企图，并提供实时或近实时的警告。【[RFC4949](./refs.md#rfc4949)】（改编）

- intrusion prevention system, 入侵防御系统

    一种能够检测入侵活动，并尝试阻止该活动的系统，理想情况下应在活动到达目标之前予以阻止。



## j


- jitter，抖动

    数据信号与理想时钟之间的时间或相位差。



## k

- key logger，键盘记录器

    一种旨在记录计算机键盘上按下的键的程序，以获取密码或加密密钥，从而绕过其他安全措施。



## l


- local area network, 局域网

    一组分散在相对有限区域内的计算机和其他设备，他们通过通信链路连接，使网络上的任何设备都能与其他设备进行交互。



## m


- machine controller，机器控制器

    一种控制系统/运动网络，他通过电子方式同步机器系统内的驱动器，而不是依赖机械联动进行同步。【[IR6859](./refs.md#ir6859)】

- maintenance, 维护

    任何旨在防止设备故障或失灵，或恢复其运行能力的操作。【[ISADICT](./refs.md#isadict)】

- malware, 恶意软件

    旨在执行未经授权的进程，且会对信息系统的机密性、完整性或可用性产生不利影响的软件或固件。指感染主机的病毒、蠕虫、特洛伊木马，或其他基于代码的实体。【[SP800-53r5](./refs.md#sp800-53r5)】（改编）

- manipulated variable，被控变量

    在旨在调节某种状态的工艺过程中，控制装置通过改变该量或状态，来引发被控状态值发生变化的量或状态。【[ISADICT](./refs.md#isadict)】

- master terminal unit，主终端单元

    参见 *[控制服务器](#control_server)*。

- modem, 调制解调器

    一种用于将发送终端的串行数字数据转换为适合通过电话信道传输的信号，并将传输的信号重新转换为接收终端所需串行数字数据的设备。【[IR6859](./refs.md#ir6859)】


## o


- operating system, 操作系统

    用于监督计算机程序执行顺序的一组集成服务例程。操作系统可执行输入/输出控制、资源调度及数据管理等功能。他为应用程序提供控制计算机的基本命令。【[ISADICT](./refs.md#isadict)】

- operational controls，运营控制措施

    主要由人员（而非系统）实施和执行的信息系统安全控制措施（即防护措施或对策）。【[FIPS200](./refs.md#fips200)】


- operational technology，运营技术

    指与物理环境交互，或管理与物理环境交互的设备的一系列可编程系统和设备。这些系统和设备通过监测和/或控制设备、流程和事件，来检测或引发直接变化。示例包括工业控制系统、楼宇自动化系统、交通系统、物理访问控制系统、物理环境监测系统以及物理环境测量系统。



## p


- password, 口令

    一串字符（字母、数字和其他符号），用于身份认证或验证访问授权。【[FIPS140-2](./refs.md#fips140-2)】

- phishing, 网络钓鱼

    通过在电子通信（例如互联网网站）中冒充可信实体，诱骗个人泄露敏感个人信息。

- plant, 工厂

    支持物理过程所需的物理要素。这可能包括许多不受 ICS 控制的静态组件。然而，ICS 的运行可能会影响工厂组件的充分性、强度和耐久性。

- port, 端口

    用于连接通信或外围设备的计算机入口或出口点。

- port scanning, 端口扫描

    使用程序远程确定系统上哪些端口处于开放状态（例如，系统是否允许通过这些端口进行连接）。

- predisposing condition, 诱发条件

    指存在于组织内部、任务/业务流程、企业架构或信息系统（包括其运行环境）中的一种状况，该状况会影响（即增加或减少）一种或多种威胁事件的概率，一旦发生，将导致对组织运营和资产、个人、其他组织或国家，造成不良后果或不利影响。【[SP800-30r1](./refs.md#sp800-30r1)】

- pressure regulator，压力调节器

    用于控制气体或液体压力的装置。【[IR6859](./refs.md#ir6859)】

- pressure sensor, 压力传感器

    一种传感器系统，可产生与其周围介质施加的压力相关的电信号。压力传感器也可利用压差，来获取液位和流量测量值。【[IR6859](./refs.md#ir6859)】 (改编)

- printer, 打印机

    一种将数字数据转换为纸质介质上人类可读文本的设备。【[IR6859](./refs.md#ir6859)】 (改编)

- process controller，过程控制器

    一种计算机系统（通常为机架式），用于处理传感器输入、执行控制算法并计算执行器输出。【[IR6859](./refs.md#ir6859)】（改编）

- programmable logic controller，可编程逻辑控制器 PLC

    一种固态控制系统，具有用户可编程存储器，用于存储指令以实现特定功能，如 I/O 控制、逻辑、定时、计数、三模式（PID）控制、通信、算术运算以及数据和文件处理。【[ISADICT](./refs.md#isadict)】

- protocol，协议

    一套用于实现和控制系统之间某种关联（例如通信）的规则（即格式和程序）。【[RFC4949](./refs.md#rfc4949)】

- protocol analyzer，协议分析仪

    一种设备或软件应用程序，可让用户分析网络数据的性能，以确保网络及其相关硬件/软件的运行符合网络规范。【[ISADICT](./refs.md#isadict)】




## r


- realtime，实时

    指在相关物理过程实际发生期间进行计算，以便将计算结果用于指导该物理过程。

- redundant control server，冗余控制服务器

    作为控制服务器的备份，始终保持控制服务器的当前状态。【[IR6859](./refs.md#ir6859)】

- relay，继电器

    一种通过物理移动导电触点，来接通或断开电路的机电设备。由此产生的运动可与阀门或断路器等其他机构耦合。 【[ISADICT](./refs.md#isadict)】

- remote access，远程访问

    用户（或代表用户行事的程序进程）通过外部网络访问组织系统的行为。【[SP800-53r5](./refs.md#sp800-53r5)】

- remote diagnostics，远程诊断

    由位于信息系统安全边界之外的人员进行的诊断活动。

- remote maintenance，远程维护

    由通过外部网络进行通信的人员开展的维护活动。 【[SP800-53r5](./refs.md#sp800-53r5)】

- remote terminal unit，远程终端单元

    配备无线电接口的计算机，用于无法通过有线通信的远程场景。通常用于与远程现场设备通信。具有无线通信能力的 PLC 也可替代 RTU 使用。【[IR6859](./refs.md#ir6859)】

- risk，风险

    在考虑威胁的潜在影响及其发生可能性的基础上，信息系统运行对机构运营（包括使命、职能、形象或声誉）、机构资产或个人造成的影响程度。【[FIPS200](./refs.md#fips200)】（改编）

- risk assessment，风险评估

    通过确定发生概率、由此产生的影响以及可减轻该影响的额外安全控制措施，来识别对机构运营（包括使命、职能、形象或声誉）、机构资产或个人的风险的过程。属于风险管理的一部分，与风险分析同义。包含威胁和漏洞分析。【[SP800-39](./refs.md#sp800-39)】（改编）

- risk management，风险管理

    管理因信息系统运行而对组织运营（包括使命、职能、形象、声誉）、组织资产、个人、其他组织及国家造成的风险的过程，包括：(i) 开展风险评估； (ii) 实施风险缓解策略；以及 (iii) 采用技术和程序对信息系统的安全状态进行持续监控。 【[FIPS200](./refs.md#fips200)】（改编）

- router, 路由器

    一种位于 OSI 第 3 层、作为两个网络之间网关的计算机，用于在网络之间中继和引导数据包。最常见的路由器处理 IP 数据包。【[RFC4949](./refs.md#rfc4949)】（改编）



## s


- safety instrumented system，安全仪表系统

    由传感器、逻辑解析器和最终控制元件组成的系统，其目的是在预定条件被违反时，将工艺过程带入安全状态。其他常用术语包括紧急停机系统 emergence shutdown system, ESS、安全停机系统 safety shutdown system, SSD 和安全联锁系统 safety interlock system, SIS。【[ANSI-ISA-84](./refs.md#ansi-isa-84)】

- SCADA 服务器

    在 SCADA 系统中充当主机的设备。

- security audit，安全审计

    对系统记录和活动进行的独立审查和检查，旨在确定系统控制措施是否充分，确保符合既定的安全政策和程序，发现安全服务中的漏洞，并就应采取的应对措施提出建议。【[ISO7498-1](./refs.md#iso7498-1)】

- security controls，安全控制措施

    为保护信息系统及其信息的机密性、完整性和可用性，针对该信息系统规定的管理、运营和技术控制（即防护措施或对策）。【[FIPS199](./refs.md#fips199)】

- security plan，安全计划

    一份正式文件，概述了信息系统的安全要求，并描述了为满足这些要求而已实施或计划实施的安全控制。【[SP800-18r1](./refs.md#sp800-18r1)】

- security policy，安全政策

    安全政策定义了安全计划的目标和约束条件。政策在多个层级制定，范围从组织或企业政策到具体的操作约束（例如远程访问）。一般而言，政策回答 “做什么” 和 “为什么” 的问题，而不涉及 “如何做”。政策通常以技术无关的术语表述。

- sensor，传感器

    一种产生电压或电流输出的设备，该输出代表所测量的某些物理属性（例如速度、温度、流量）。【[ISADICT](./refs.md#isadict)】

- set point，设定点

    一个用于设定被控变量目标值的输入变量。该变量可以手动设定、自动设定或通过编程设定。【[ISADICT](./refs.md#isadict)】

- single loop controller，单回路控制器

    用于控制非常小的过程或关键过程的控制器。【[IR6859](./refs.md#ir6859)】

- social engineering，社会工程学

    试图诱骗他人透露可用于攻击系统或网络的信息（例如口令）的行为。【[SP800-61r2](./refs.md#sp800-61r2)】

- supervisory control，监督控制

    该术语用于表示控制器或计算机程序的输出，被用作其他控制器的输入。参见 *[控制服务器](#control_server)*。【[ISADICT](./refs.md#isadict)】

- supervisory control and data acquisition, 监督控制与数据采集 SCADA

    指能够远程采集和处理数据并实施运行控制的计算机化系统的通用名称。典型应用包括电力传输与分配以及管道系统。SCADA 专为应对各种通信媒介（如电话线、微波和卫星）带来的独特通信挑战（例如延迟、数据完整性）而设计。通常为共享而非专用。【[ISADICT](./refs.md#isadict)】



## t


- technical controls，技术控制措施

    信息系统的安全控制（即防护措施或对策），主要由信息系统通过其硬件、软件或固件组件中的机制来实施和执行。【[FIPS200](./refs.md#fips200)】

- threat，威胁

    任何可能通过信息系统，以未经授权的访问、破坏、披露、修改信息和/或拒绝服务等方式，对机构运营（包括安全、任务、职能、形象或声誉）、机构资产或个人造成不利影响的情况或事件。【[FIPS200](./refs.md#fips200)】（改编）

- threat event，威胁事件

    可能导致不良后果或影响的事件或情况。【[SP800-30r1](./refs.md#sp800-30r1)】

- threat source，威胁源

    指旨在蓄意利用漏洞的意图和方法，或可能意外触发漏洞的情况和方法。*与 “威胁源头，threat agent” 同义*。【[FIPS200](./refs.md#fips200)】

- Transmission Control Protocol，传输控制协议

    TCP 是 TCP/IP 网络中的主要协议之一。IP 协议仅处理数据包，而 TCP 则使两个主机能够建立连接并交换数据流。TCP 保证数据的送达，并保证数据包将按发送时的顺序送达。

- Trojan horse，特洛伊木马

    一种看似具有有用功能的计算机程序，但同时具有隐藏的、潜在的恶意功能，能够规避安全机制，有时通过利用调用该程序的系统实体的合法授权来实现。【[RFC4949](./refs.md#rfc4949)】



## u


- unauthorized access，未授权访问

    指某人未经许可，对网络、系统、应用程序、数据或其他资源获得逻辑或物理访问权限。【[SP800-61](./refs.md#sp800-61)】

- unidirectional gateway，单向网关

    单向网关是由硬件和软件组成的组合体。该硬件允许数据从一个网络流向另一个网络，但在物理上完全无法将任何信息发回源网络。软件则负责复制数据库并模拟协议服务器和设备。



## v


- valve，阀门

    流体流动系统中的一种管线内设备，可中断流体流动、调节流速，或将流体分流至系统的另一支路。【[ISADICT](./refs.md#isadict)】

- virtual private network, 虚拟专用网络 VPN

    一种受限使用的逻辑（即人工或模拟）计算机网络，他由相对公开的物理（即真实）网络（如互联网）的系统资源构建而成，通常通过（位于主机或网关上的）加密技术实现，并常通过在真实网络上建立虚拟网络的隧道连接来实现。【[RFC4949](./refs.md#rfc4949)】（改编）

- virus，病毒

    计算机软件中隐藏的、能够自我复制的部分，通常为恶意逻辑，通过感染（即向另一个程序中插入自身副本并成为其组成部分）来传播。病毒无法独立运行；他需要其宿主程序运行才能激活。【[RFC4949](./refs.md#rfc4949)】（改编）

- vulnerability，漏洞

    信息系统、系统安全程序、内部控制或实施中的薄弱环节，可能被威胁源利用或触发。【[FIPS200](./refs.md#fips200)】



## w


- wide area network，广域网

    一种物理或逻辑网络，其服务范围内的独立用户数量通常超过局域网 LAN 的典型服务范围，且通常覆盖的地理区域比局域网更广。

- wireless device，无线设备

    任何可通过无线电或红外波连接到 OT 网络的设备，通常用于收集或监控数据，但在某些情况下也可用于修改控制设定点。

- workstation，工作站

    用于编程、工程和设计等任务的计算机。【[IR6859](./refs.md#ir6859)】

- worm，蠕虫

    一种能够独立运行的计算机程序，能够将自身的一个完整且可运行的副本传播到网络上的其他主机，并可能以破坏性方式消耗计算机资源。【[RFC4949](./refs.md#rfc4949)】（改编）
