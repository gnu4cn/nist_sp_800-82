# 摘要

本文件就如何在满足运营技术（OT）独特的性能、可靠性和安全要求的同时保障其安全提供了指导。OT涵盖了广泛的可编程系统和设备，这些系统和设备与物理环境进行交互（或管理与物理环境交互的设备）。这些系统和设备通过监测和/或控制设备、流程和事件，来检测或引发直接变化。典型示例包括工业控制系统、楼宇自动化系统、交通系统、物理访问控制系统、物理环境监测系统以及物理环境测量系统。本文件概述了OT及其典型系统拓扑结构，指出了这些系统面临的常见威胁和漏洞，并提供了建议的安全对策以减轻相关风险。

# 关键词

计算机安全；分布式控制系统（DCS）；工业控制系统（ICS）；信息安全；网络安全；运营技术（OT）；可编程逻辑控制器（PLC）；风险管理；安全控制措施；监督控制与数据采集（SCADA）系统。

# 计算机系统技术报告

美国国家标准与技术研究院（NIST）下属的信息技术实验室（ITL）通过为国家的计量和标准基础设施提供技术领导力，促进美国经济和公共福利。ITL 开发测试、测试方法、参考数据、概念验证实现方案和技术分析，以推动信息技术的开发和有效应用。ITL的职责包括制定管理、行政、技术及物理标准和指南，以确保联邦信息系统中非国家安全相关信息的经济高效的安全与隐私保护。800系列特别出版物报告了ITL在信息系统安全方面的研究、指南和推广工作，以及其与行业、政府和学术组织的合作活动。
