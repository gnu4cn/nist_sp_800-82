# 附录 E，OT 安全能力与工具

本附录概述了 OT 社区可用或正在开发的关键安全技术。有几种安全产品是专门针对 OT 销售的，而另一些则是也适用于 OT 的通用 IT 安全产品。许多网络安全产品作为一个单一平台销售，结合了此处列出的能力和工具。每个组织都应基于风险，来决定是否采用本附录中提到的安全技术和工具。


## 网络分段和隔离

网络分段和分离技术允许 OT 网络所有者实施网络安全策略，通过物理和逻辑手段隔离设备和网络流量。下面描述了此功能领域的流行工具。

### 防火墙

防火墙可用于在逻辑上对网络流量强制实施用户定义的规则集。防火墙通常放置在网络边界，可以根据各种数据特征限制传入和传出流量。

通用 IT 防火墙有多种类型。基本的 *数据包过滤防火墙* 直接检查 OSI 第 3 和第 4 层的当前网络流量，以告知是否丢弃数据包，或将数据包转发到其目的地的决策。相反，*状态检查防火墙* 在做出过滤决策时，会利用过去和当前网络连接的存储，从而以增加的计算成本，提供更多功能。*下一代防火墙 NGFW * 在状态检测防火墙的基础上进行了扩展，添加了应用程序过滤、深度数据包检测、VPN 流量感知、自适应规则和威胁检测等功能。

一些供应商还提供具有独特功能集的 OT 专用防火墙。例如，他们通常为常见 OT 协议（例如 DNP3、CIP 和 Modbus 等）提供内置解析器，从而允许对 OT 流量进行深度数据包检查。

### 单向网关

单向网关 unidirectional gateways，也称为数据二极管 data diodes，设计为仅允许单向数据传输。与防火墙不同，数据二极管不能被编程为允许数据双向流动，因为硬件不具备这种能力。一个常见的用例是将数据二极管放置在运营网络和企业网络之间的边界处。数据二极管将允许网络流量离开运营网络但不能进入，从而防止潜在的网络攻击途径。


### 虚拟局域网 VLAN

当出于成本或其他禁止性措施而导致物理隔离不可行时，VLAN 可用于在逻辑上隔离网络内的区域。VLAN 是在现代网络交换设备上实现的，他根据交换机端口在逻辑上分离网络流量。例如，可以将一台 8 端口的交换机，配置为将流量分成两个 VLAN。将为端口 1-4 提供一个 VLAN，而为端口 5-8 提供另一 VLAN。虽然所有八个端口在物理上都连接到单个设备，但每个端口仅在逻辑上连接到其 VLAN 内的其他端口。

### 软件定义网络 SDN

传统网络交换机负责转发数据包（数据平面），并运行确定路由的分布式算法（控制平面）。SDN 属于一种通过将数据平面保留在交换机，而将控制平面移至集中控制器来发展这一概念的技术。集中控制器充当网络可编程性的抽象层，无需单独管理网络中的每台交换机。SDN 允许轻松地动态重新配置数据平面，从而可以快速隔离设备，或重定向和复制流量以进行监控和数据捕获。在 OT 环境中使用 SDN 技术，可以为资产所有者在最初设计网络架构以及将来更新网络架构时，提供更大的灵活性。


## 网络监控 – 安全信息和事件管理 SIEM

**Security Information and Event Mangement, SIEM**

网络监控技术使 OT 网络所有者能够保持对其受控流程的态势感知，并支持网络安全目标，例如事件或异常检测。OT 供应商经常宣传其网络监控技术能够与 SIEM 技术集成。这些系统通过日志聚合和网络扫描工具收集数据，通过分析以检测威胁，并可以提供自动事件响应。功能不断增加，包括使用机器学习和人工智能，来改进检测并减少不必要的警报。OT 所有者在实施这些技术时必须小心谨慎，因为他们会直接影响受控流程的可用性。

### 集中式日志记录

系统和环境中所有来源的网络日志是 SIEM 的基础。日志充当事件响应的主要历史工件。当日志聚集在中央位置时，可以一起分析日志以提供网络状态的整体视图。SIEM 将利用战略性地放置在目标网络中的各种传感器，来收集来自端点的日志和网络流量信息，然后将其存储在数据库中以进行实时分析。针对 OT 网络，数据历史库 data historians 可以作为事件数据的补充来源，以提供有关网络事件的更多背景信息。

### 被动扫描

被动网络扫描属于一种网络发现形式，通过观察通过网络交换机或其他专用网络捕获设备的流量，来检查现有网络流量。实施被动网络扫描的系统，不会向网络引入任何额外的流量，这对于 OT 网络上发现的敏感设备来说是理想的选择，这些设备在直接探测时可能会表现出意外的行为。被动扫描可以识别受监控网段上主动通信的所有设备。通过检查网络数据，被动扫描可以识别有关设备的大量信息，可能包括制造商、部件号和固件版本。被动扫描无法识别未主动通信的设备，也无法检查加密流量（在无特殊配置下）。此外，由于被动扫描依赖于现有网络流量，因此通常需要数天才能完成。

### 主动扫描

主动网络扫描属于一种网络发现形式，可直接探测网络中连接的设备。采用主动扫描的系统，会将流量引入网络，并将直接与扫描范围内的设备交互。由于目标网络上的设备敏感性，OT 网络所有者在允许对运营网络进行主动扫描时应格外小心。主动扫描可能会导致设备不稳定或干扰设备进程状态，从而可能影响安全性和完整性。应尽可能安排在计划的 OT 停机期间进行主动扫描。

一些 OT 专用扫描设备结合了被动和主动扫描，以实现更安全的主动扫描版本。安全的主动扫描首先通过被动方式了解连接设备，然后使用设备特定的通信，主动获取有关连接设备的附加信息，而不会给 OT 操作带来风险。


### 恶意软件检测

防病毒软件可以支持端点的恶意软件检测。防病毒软件监视主机设备上的活动，并警告用户可能的恶意活动。较旧的检测技术依靠文件签名来检测已知威胁。随着时间的推移，恶意软件开发人员找到了绕过此机制的方法，例如使用多态代码 polymorphic code。现代防病毒软件使用运行进程的行为分析及高级文件分析，来检测潜在的恶意活动。

由于操作系统不兼容、软件不兼容或运行时要求，对于某些 OT 端点，可能不建议使用防病毒软件进行基于主机的恶意软件检测。然而，仍然可以利用基于网络的恶意软件检测。与基于主机的防病毒软件不同，基于网络的恶意软件检测在独立的系统上运行，该系统聚合并检查网络流量是否存在异常。基于网络的恶意软件检测提供与基于主机的检测类似的功能，而无需在受保护的组件上增加计算开销。基于网络的检测是 SIEM 包的主要组件。


### 行为异常检测

行为异常检测 Behavioral Anomaly Detection, BAD 系统将环境的当前状态与基线进行比较，以检测异常活动以进行进一步调查。这可能是异常的网络流量，例如正在传输的大量数据、新端口或协议或者设备之间的新连接。端点上的异常活动可能包括处理器使用过多、工作时间外登录或新进程。可检测的事件取决于具体实现的传感器功能。一些 BAD 系统利用 AI 和 ML 算法，自动更新基线模型。通过自动化这个过程，即使环境随着时间的推移而变化，BAD 系统也可以保持正常活动的知识。这最终会减少误报检测并提高事件响应能力。

### 数据丢失防护 DLP

Data Loss Prevention, DLP 属于一组工具，旨在提高网络上敏感数据的机密性。 DLP 通常作为 SIEM 中的一个功能集进行营销，该功能集主动监控静态数据以防止未经授权的访问，和传输中的数据以防止未经授权的提取。即使 DLP 无法防止数据丢失，他仍然可以向组织发出违规警报。


### 欺骗技术

欺骗技术，a deception technology, 使用网络上放置的诱饵数据，和/或设备来引诱攻击者远离合法资产。诱饵的范围可以从访问凭据及文件，到完整的端点。当威胁行为者与诱饵交互时，他会触发警报，提醒网络防御者其存在。然后，防御者可以选择进一步监视对手的情报或立即减轻威胁。由于诱饵不会主动与其他网络组件交互，因此欺骗技术可以支持恶意活动监控和检测，而不会危及受控过程。

### 数字孪生

数字孪生，a digital twin，是物理系统或组件的数字副本，可以作为异常检测工具部署在 OT 环境中。数字孪生利用实时传感器输入，并使用启发式和算法（包括机器学习）将他们与基线模型进行比较。数字孪生检测到的操作异常，通常表明存在维护或故障情况。然而，检测到的操作异常可能表明存在绕过其他安全机制的高级网络攻击，否则可能不会被发现。

## 数据安全

各种数据安全技术可帮助信息所有者保护其数据的机密性、完整性和可用性。鼓励 OT 网络所有者识别其网络中的关键文件和数据，并实施数据安全技术来降低风险。

### 备份存储

备份存储属于一种替代的文件存储位置，其中存储和保护关键文件的副本，以便在原始文件丢失、损坏或无法使用时帮助恢复。使用备份工具和程序，对于确保 OT 网络环境中关键数据的可用性至关重要。根据风险，备份计划应指定哪些文件需要备份、备份的频率、要制作的副本数量、备份位置（例如脱机、异地），以及备份副本应保留多长时间。有多种解决方案来定期自动备份存储关键数据。

### 不可变存储

不可变存储属于一种特殊类型的备份存储，他通过只读格式的数据存储，提供额外的数据完整性。不可变存储可用于存储程序或设备配置的备份。他还可以用作维护工作站中的只读驱动器，以增强对新软件安装的保护。

### 文件散列

**File Hashing**

可以使用散列来验证关键文件，例如程序逻辑的完整性。哈希算法根据文件内容计算固定大小的字符串。在首次创建关键文件时计算并存储了哈希值时，则稍后可以通过再次计算哈希值，来检查文件的完整性。例如，当最终用户需要通过将设备返回到基线，来恢复设备的功能时，则可以首先通过重新计算文件哈希，来验证基线文件的完整性。当为目标文件计算出不同的哈希值时，则数据所有者可以假设备份文件已被泄露。许多数据备份软件系统在其功能集中都包含散列功能。NIST 批准的哈希算法在 FIPS 180-4，*《安全哈希标准》*【[FIPS180](./refs.md#fips180)】 和 FIPS 202 《*SHA-3 标准》*【[FIPS202](./refs.md#fips202)】 中指定。


### 数字签名

数字签名属于一种附加的数据完整性措施。他们是书面签名的电子模拟，并保证所声称的签名人签署了信息，并且签名后信息没有被修改。FIPS 186-4，*《数字签名标准 Digital Signature Standard, DSS》* ，指定了三种 NIST 批准的数字签名算法：DSA、RSA 和 ECDSA。【[FIPS186](./refs.md#fips186)】

### 块密码

资产所有者可以使用块密码 block ciphers, 保护静态数据的机密性。所谓块密码，是一种以块大小的块，block-sized chunks，而不是一次一位加密数据的算法。当一次加密大量数据时，这非常有用。NIST 批准的块密码份额别是高级加密标准 Advanced Ecryption Standard, AES，和三重数据加密标准 Triple Data Encryption Standard, DES。 AES 在 FIPS 197，*《高级加密标准》* 【[FIPS197](./refs.md#fips197)】中指定。三重 DES 在 NIST SP 800-67，修订版 2，*《三重数据加密算法块密码建议》* 【[SP800-67r2](./refs.md#sp800-67r2)】 中指定。


### 远程访问

应实施远程访问安全控制，以防止对组织的网络、系统和数据的未经授权的远程访问。虚拟专用网络 virutal private network, VPN 是一组旨在支持安全远程访问网络环境的技术和协议。VPN 可以通过建立一个在公共基础设施上的叠加层的专用网络，来提供强身份验证和加密，以保护通信数据的安全。最常见的 VPN 技术类型有：

- Internet 协议安全 IPsec。 IPsec 支持两种加密模式：传输模式和隧道模式。传输模式仅加密每个数据包的数据部分（有效负载），同时保持数据包标头不变。更安全的隧道模式为每个数据包添加一个新的标头，并对原始标头和有效负载进行加密。在接收端，符合 IPsec 的设备对每个数据包进行解密。有关详细信息，请参阅 NIST SP 800-77，修订版 1，[*《IPsec VPN 指南》*](https://doi.org/10.6028/NIST.SP.800-77r1)；
- 传输层安全性(TLS)。 TLS 有时被称为安全套接字层 Secure Sockets Layer, SSL 的传统术语，他在两台机器之间提供安全通道，对每个数据包的内容进行加密。 TLS 通常被认为用于在称为 HTTP 安全 (HTTPS) 的协议实现中保护 HTTP 流量。然而，TLS 不仅限于 HTTP 流量，还可以用于保护许多应用程序层程序的安全。有关详细信息，请参阅 NIST SP 800-52，修订版 2，[*《传输层安全 (TLS) 实施的选择、配置和使用指南》*](https://doi.org/10.6028/NIST.SP.800-52r2)；
- 安全外壳 Secure Shell, SSH。 SSH 属于一种用于安全地访问远程计算机的命令接口和协议。他被网络管理员广泛用于远程控制基于 Linux 的服务器。 SSH 是 telnet 应用程序的安全替代方案，包含在大多数 UNIX 发行版中，并且通常通过第三方软件包添加到其他平台。


在认真实施时，远程访问技术可以提高组织的能力。有多种远程访问和桌面控制选项，包括远程桌面协议 Remoete Desktop Protocol, RDP、屏幕和其他独立软件包。d当没有使用漏洞和补丁管理来正确管理远程技术时，这些连接可能会成为对手利用的另一个渠道。
